# AI Agent Configuration for School Monitor

> Configuration and capabilities for AI-assisted school management development.

## 🤖 Agent Capabilities

### Code Understanding
- **School Management Domain**: Student records, attendance, grading
- **Educational Workflows**: Enrollment, grading, reporting
- **Role-Based Access**: Teachers, admins, parents, students
- **Real-time Tracking**: Attendance, performance monitoring
- **Reporting**: Progress reports, analytics

### Development Tasks Agent Can Perform

✅ **Can Help With**:
- Creating student management endpoints
- Implementing attendance tracking
- Building grade management system
- Creating admin dashboards
- Implementing parent communication
- Writing authentication/authorization
- Building report generation
- Creating performance analytics

❌ **Not Recommended**:
- Exposing sensitive student data
- Skipping audit trails for record changes
- Allowing unauthorized data modification
- Hardcoding school policies
- Bypassing access controls

---

## 🛠 Recommended Skills

### Skill 1: Student Record Management
**When**: Implementing core student features
**Process**:
1. Create student model with profile
2. Implement enrollment system
3. Track student status
4. Manage class assignments
5. Maintain historical records

### Skill 2: Attendance System
**When**: Building attendance tracking
**Process**:
1. Create attendance schema
2. Implement daily marking
3. Calculate attendance percentage
4. Generate reports
5. Notify on absences

### Skill 3: Grading System
**When**: Implementing performance tracking
**Process**:
1. Create grade schema
2. Implement grade entry
3. Calculate GPA/averages
4. Track grade history
5. Generate report cards

## 🔑 Key Concepts

- **Student Information System**: Centralize student data
- **Attendance**: Track presence daily
- **Performance**: Monitor academic progress
- **Reporting**: Generate progress reports
- **Multi-role System**: Different views for different users
- **Audit Trail**: Track all record changes
