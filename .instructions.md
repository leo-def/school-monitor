# Development Instructions for AI Agents - School Monitor

> Guidelines for AI-assisted development of the school management system.

## 🎯 Project Overview

- **Purpose**: School management and monitoring platform
- **Type**: Full-stack web application
- **Tech Stack**: Frontend + Backend + Database
- **Build**: npm/yarn with modern tooling

---

## 🏗 Architecture Pattern

**School Management System**:
- **Frontend**: Dashboard for teachers, admins, and parents
- **Backend**: REST API for school operations
- **Database**: Student, attendance, grade records

### Core Features
```
Student Management      - Profiles, enrollment
Attendance Tracking     - Daily records
Performance Monitoring  - Grades and analytics
Reporting              - Progress reports
Communication         - Parent/student notifications
```

---

## 📂 File Naming & Conventions

**Backend Files**: camelCase
- `studentController.js`, `attendanceService.js`

**Frontend Components**: PascalCase
- `StudentDashboard.tsx`, `AttendanceList.tsx`

**Routes**: RESTful patterns
- `/api/students`, `/api/attendance`, `/api/grades`

**Variables**: descriptive camelCase
- `studentId`, `attendanceDate`, `gradeValue`

---

## ✅ DO's

1. **DO** validate all student data input
2. **DO** implement role-based access control
3. **DO** track attendance with timestamps
4. **DO** maintain grade history
5. **DO** provide comprehensive reporting

---

## ❌ DON'Ts

1. **DON'T** expose sensitive student data without authorization
2. **DON'T** allow modification of attendance records without audit trail
3. **DON'T** skip input validation
4. **DON'T** hardcode school data
5. **DON'T** allow unauthorized parent access

---

## 📋 Common Workflows

**Setting up new school**:
1. Create school profile
2. Add classes and sections
3. Enroll students
4. Register teachers
5. Configure academic calendar

**Recording attendance**:
1. Select date and class
2. Mark present/absent
3. Save to database
4. Notify absent students

**Managing grades**:
1. Create assessment
2. Enter grades for students
3. Calculate averages
4. Generate report cards
